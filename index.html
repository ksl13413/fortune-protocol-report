本尊：Fortune Protocol（Fortune Cookie Protocol）

官网 fortuneprotocol.io，2026-11-19 实测可访问。定位是 BNB Chain 上的预测市场聚合协议，口号「Crack a cookie. Predict the future.」，页脚署名「© 2026 FORTUNE COOKIE PROTOCOL」，已集成 Polymarket 与 Predict.fun 的市场。官方 X 只有一个：@fortuneglobal_（简介「Built on BNB」，2026 年 3 月加入）。群头像上的「FPoints Transfer Feature」与官网积分转账功能完全对应——这是身份确认最强的直接证据。

来源：官网实测（verified live）；X 账号经 TopKOLs 抓取

「积分」= F Points（F）

Fortune 的站内积分 / 空投权重，不是代币、不是链上资产，官网未公布任何 F 的合约。获取方式：预测市场交易、每日签到开「幸运饼干」、Council 投票、完成任务、用 Fortune Agent；邀请人可得被邀请人 F 的 10%。

官方 X 原文：F Points 记录你在平台的全部活动，持续累积、永不过期，「can be converted directly into an airdrop allocation」（可直接转换为一次空投分配）。

但比例从未公布官方从未公布 F 兑换 $FORTUNE 的比例、快照规则或分配总量。截至 2026-10-14 的官方 Medium 还明确写着快照日期未公布。

「卡牌」= Fortune Node NFT 置信度高 · 非 100%

Fortune 生态里唯一的 NFT / 卡类资产就是 Node NFT，未发现任何其他官方「卡牌」产品。群里「积分 + 卡牌」打包卖的模式，与 Node NFT「买即得 40,000 F」的机制完全吻合。未看到群内 NFT 合约地址或图片，无法 100% 排除是别的卡类资产；且 Node NFT 官方图是一只幸运饼干，并非卡片造型。

F 积分转账：官方功能真实存在，但有两道硬限制

官网 /profile 页实测：TOTAL F 框右上角有转账图标，点击弹出「Transfer F」窗口（收款地址、金额、余额、MAX、确认）。弹窗原文规则：「One transfer per day, each transfer up to the balance of 99%.」——每天只能转 1 次，单次至多转出余额的 99%。

  • 「10w 积分」一次最多到账 99,000，剩下的 1% 次日再转 99%，以此类推，理论上永远转不干净；
  • 没法「小额验货」：试转一笔小额，就把当天唯一一次机会用掉了；
  • 转账是否链上交易、是否可撤销、是否收费、是否会被风控或快照排除——官网均未说明，未核实。
场外买卖官方允不允许？没有表态。官网、GitBook 文档、白皮书、官方 Medium 均未检索到允许或禁止 OTC 的条款。转账是中性产品功能，不能解读成官方背书场外交易；也没有条文说卖积分会封号。定性：灰色地带、无保障。

若「10:1」为真100,000 F = 10,000 代币打包价 $290 且卡牌本身值 $300，则代币隐含价值为负——报价与 10:1 无法自洽，再次说明 10:1 不可信，或报价中的「卡牌」不是 300 USDT 的 Node NFT

情形 B：数字是人民币（QQ 群常见）

¥290 ≈ $40，仅为官方铸造价的约 13%；单卡 ¥60–80 亦然。折价大到不合常理，更可能指向：急于离场的亏损卖家、并非 Node NFT 的便宜卡、或诱饵报价（先报低价引流，交易时再变卦 / 换人）。

一个只能看、不能用的锚按官方铸造结构，300 USDT 买卡即得 40,000 F，若把卡的全部价值都算在 F 上，每 F ≈ $0.0075，10 万 F ≈ $750，打包价 $290 远低于此。但这个锚本身无意义：40,000 F 只是赠品，卡的价值还含 1.1 倍加成与未兑现的分红承诺，且没有任何人按 $0.0075/F 收过积分。别拿它当「便宜」的依据。

结论：无论按哪种币种，场外价都远低于官方铸造价。合理解释只有四种，且都对买方不利或存疑：① 卖家对 TGE 失望、割肉离场（「卡牌不上线不值钱」正是这种情绪）；② 市场根本不信官方价，认为 300 USDT 定价过高；③ 卖的不是 Node NFT；④ 报价是骗局诱饵。折价本身不是捡漏证据，是风险信号。

针对这个项目的 9 种具体坑法

  1. 先款后货，卖家消失。QQ 交易无托管、无仲裁、无退款。反过来卖家先转、买家不付，卖家同样受害——于是骗子常冒充「中介 / 担保」介入。
  2. 假中介。克隆群主 / 中介的头像昵称私聊你：「款打给我，我担保。」官方已警告假账号泛滥，QQ 群内更难分辨。
  3. 假截图。积分余额截图可用开发者工具、另一个账号、P 图伪造。唯一可信的验证是卖家当面在官网完成一次真实转账到你的地址——但这与下一条冲突。
  4. 「每天 1 次转账」陷阱。卖家先转一笔小额「验货」，当天就不能再转大额；分多日转则要承担隔夜风险（快照、跑路、价格变动）。任何「先付全款、明天再转」的安排都应拒绝。
  5. 99% 上限陷阱。按 10 万报价付款、只收到 9.9 万，是规则使然，不是卖家克扣——交易前必须把这一点算进价格。
  6. 假卡 / 假 NFT。Node NFT 的官方合约地址未在官网公布，你无法在 BscScan 上独立验证「这张卡是不是真的」。骗子可铸造同名同图的假 NFT 卖给你。
  7. 「单卡牌不要」的含义。买方只要打包、不要单卡，说明单卡几乎没有二级市场：卡的价值主要来自附带的 40,000 F 与 1.1 倍加成，而二手卡转让后加成是否保留、基础 F 是否还在原账户，官网均未说明。买到单卡，可能只剩一个无明确权益的 NFT。
  8. 快照 / 女巫风险（未证实、须警惕）。项目方从未说明受让积分是否计入空投、是否会被视为女巫 / 刷分排除。快照规则公布前，受让积分存在被清零或打折的制度风险，且买方无法事前验证。
  9. 与仿盘混淆。有人可能拿仿盘地图里 B / C / D / E / F 的代币或「卡」冒充本尊资产卖给你，或发仿站链接诱导你连钱包授权。只认 fortuneprotocol.io 一个域名与 @fortuneglobal_ 一个 X 账号。

「卡牌不上线不值钱」——这句话基本是对的

  • F 积分 → $0：积分唯一公开用途是兑换未来空投分配；无 TGE 即无分配。积分不能提现、不能换 BNB、不能兑换任何实物（Profile 页的「Withdraw BNB」是邀请 / 交易奖励的 BNB，与 F 无关）。
  • Node NFT → 接近 $0 的收藏品：分红依赖平台手续费，而手续费规模从未披露（AInvest 指出 Fortune 未披露 Polymarket 侧成交量数据）；官网现行表述已把分红弱化为「可能有资格参与生态功能」。无官方二手交易场所，QQ 群报价已显示流动性枯竭（单卡无人要）。
  • 时间成本：自 2026-08-21 称「TGE 临近」至今近 3 个月无日期；Predict.fun 的延期先例表明「临近」可以无限延长。持有期间资金完全锁定，无利息、无退出通道。
